# Sistema de Cadastro de Produtos

Este projeto é um **sistema simples de gestão de estoque em Python**, desenvolvido para cadastrar e controlar produtos de uma loja de **sportswear e surf**.

O programa funciona em **modo terminal** e permite ao usuário gerenciar produtos através de um menu interativo.

## Funcionalidades

O sistema possui as seguintes funções:

1. **Adicionar produto** ao estoque
2. **Excluir produto** do estoque
3. **Atualizar quantidade** de produtos em estoque
4. **Alerta de estoque baixo** (produtos com menos de 50 unidades)
5. **Listar todos os produtos cadastrados**

## Estrutura do Projeto

O projeto é dividido em dois arquivos principais:

* **main.py**
  Responsável por exibir o menu e controlar o fluxo do programa.

* **funcoes.py**
  Contém todas as funções relacionadas à gestão dos produtos e manipulação do estoque.

## Como executar o projeto

1. Certifique-se de ter o **Python instalado** no computador.
2. Coloque os arquivos `main.py` e `funcoes.py` na mesma pasta.
3. Abra o terminal na pasta do projeto.
4. Execute o comando:

```
python main.py
```

5. O menu do sistema será exibido no terminal.
